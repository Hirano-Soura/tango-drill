# tango-drill

英単語を**自分の単語帳**として登録し、4 択・カードで復習する Web アプリ(開発中)。
授業での利用を想定し、サーバーを持たず、学習記録は利用者の端末の中だけに保存する方針。

設計と進捗は [Docs/00_Index.md](Docs/00_Index.md) から辿れる。

## 開く場所

| 場所 | URL | 使う場面 |
| --- | --- | --- |
| GitHub Pages | `https://hirano-soura.github.io/tango-drill/` | リポジトリの Settings → Pages で「Deploy from a branch」・`main`・`/ (root)` を選ぶと開けるようになる。授業で案内する前に先生の了承を取る |
| 同じ Wi-Fi の PC | `http://<PC の IP アドレス>:8765/` | 公開せずにスマホの実機で確かめるとき。下の「スマホで開く」 |
| 手元の PC | `http://127.0.0.1:8765/` | 開発中の確認。下の「手元で動かす」 |

単語帳と記録は**開いたブラウザ・オリジンごとに別々に**保存される。オリジンは URL のパスより前の部分
(`https://hirano-soura.github.io` や `http://127.0.0.1:8765`)で、上の表の 3 つの場所はどれも別の単語帳になる。
**同じオリジンの別のパスでは分かれない**([Docs/22_Storage.md](Docs/22_Storage.md) §4)。移すときはバックアップを使う。

## 使い方

画面は 6 つのタブに分かれる。単語帳が空なら「追加」から、語があれば「学習」から始まる。

| タブ | できること |
| --- | --- |
| 学習 | 復習ミックス(直近の回・1 回前・3 回前の語、よく間違える語、回答の少ない語。同じ日に追加した語が 1 回)か、出題順(すべての語のシャッフル・回答数の少ない順・最後に解いてから時間がたった順・追加日の新しい順 / 古い順・正答率の低い順)と語数を選んだ語を、2 段階の 4 択かカードで解く。4 択は「わかる / わからない」を先に答えてから意味を選ぶ。途中で中断して続きから再開できる。見出し語と例文を読み上げられる(端末の中にある英語の音声を使う) |
| 単語帳 | 語の一覧・絞り込み・印・編集・削除 |
| 追加 | 1 語ずつ手で足す。覚えたい語から AI への依頼文を作ってコピーする。AI の返答や表計算からのコピーを貼り付け(またはファイルを選び)、確認表で行ごとに確かめてからまとめて取り込む |
| 記録 | 語ごとの正誤・思い違いの集計、並べ替え、CSV の保存 |
| 設定 | 4 択の誤答に内蔵の語彙を使うか。読み上げ(自動読み上げ・音声・速さ)。バックアップの書き出しと読み込み |
| Q&A | よくある質問と、改善アンケート(Google フォーム。新しいタブで開く)へのリンク |

- 追加・編集・削除・取り込みの直後は、画面の下の「元に戻す」で 1 回だけ取り消せる
- 学習の記録や単語は外部に送信しない。ブラウザのデータを消すと単語帳も消える

### バックアップ(機種変更・別の端末へ移す)

1. 元の端末の「設定」→「書き出す」。`tango-drill_backup_YYYY-MM-DD.json` が保存される
2. そのファイルを移す先の端末へ渡す(AirDrop・クラウドのドライブ・メールなど)
3. 移す先の「設定」→「バックアップを読み込む」でファイルを選ぶ。読み込むファイルと今の単語帳の語数・記録件数・印の数が並ぶので、確かめてから「置き換える」
4. 間違えたときは「読み込む前の単語帳に戻す」。次にバックアップを読み込むまで使える(読み込んだあとの変更は消える)

### AI に単語カードを作ってもらう

1. 「追加」→「AI に頼む」に覚えたい語を 1 行に 1 つ書き、「依頼文を作る」→「依頼文をコピー」
2. ChatGPT・Claude・Gemini などに貼る。このアプリから AI へは何も送らない
3. 返ってきた答えを「まとめて取り込む」の欄にそのまま貼り、例文の出どころを「AI」にして「確認表を作る」。確かめてから「確定して取り込む」

### toeic-drill からの移行

[Docs/22_Storage.md](Docs/22_Storage.md) §6 の手順でバックアップのファイルを作り、上の「バックアップを読み込む」で入れる。

## 開発

必要なもの: Node.js 20 以上、Python 3.10 以上。

```bash
npm install
```

```bash
npm run check
```

挙動(`node --test`)と型(`tsc`)を検査し、結果を `Temp/tango-drill_check.txt` に書く。

```bash
python Tools/DocAudit/doc_audit.py
```

文書を検査し、結果を `Temp/tango-drill_doc_audit.txt` に書く。

## 手元で動かす

ビルド工程は無い。静的サーバーを立てて `http://127.0.0.1:8765/` を開く。

```bash
node Tools/Dev/serve.mjs
```

### スマホで開く(同じ Wi-Fi)

PC とスマホを同じ Wi-Fi につなぎ、PC で次を実行する。表示された `from the same network:` の URL をスマホのブラウザで開く。

```bash
node Tools/Dev/serve.mjs 8765 0.0.0.0
```

- Windows で初めて実行すると、ファイアウォールの許可を求められる。「プライベート ネットワーク」を許可する
- 同じネットワークの誰でも開けるので、確かめ終えたら止める(Ctrl+C)。`.git`・`Temp`・`node_modules` は配らない
- 学校や公共の Wi-Fi では端末どうしの通信が遮られて開けないことがある。そのときは自宅の Wi-Fi か GitHub Pages を使う

画面の通し確認(Playwright。端末に入っている Edge を使う)は次のとおり。結果は `Temp/tango-drill_e2e.json` に書く。

```bash
npm run e2e
```

Edge の無い端末では、別のブラウザを指定する(`PW_CHANNEL=chrome npm run e2e`)か、
入っている Chromium の実行ファイルを指定する(`PW_EXECUTABLE=<Chromium のパス> npm run e2e`)。
